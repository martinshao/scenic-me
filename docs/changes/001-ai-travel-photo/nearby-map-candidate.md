## 已确认决定

采用方案 A：地图作为“附近打卡点”创作流程中的场景选择工具，不升级为底部导航中的一级“发现”页面。

城市来源同时提供两种方式：定位当前城市与手动选择城市。两种方式在城市选择层中并列呈现，手动选择不依赖定位权限。

地图的用户任务不是普通导航，而是回答三个问题：附近哪里值得拍、现在适合什么画面、选择后如何立即开始生成。

## 选定方案：流程内地图

用户从首页点击“发现附近打卡点”后进入全屏地图，定位或搜索附近场景；选择一个地图标记，在底部预览景点、距离、推荐光线和可用机位，然后点击“使用这个场景”，继续已有的肖像、风格与生成流程。

推荐依据：

- 保持 D-005 已确认的“按任务开始”首页，不改变四项一级导航。
- 地图直接服务一次创作，用户选完景点就能得到明确下一步。
- 可先验证“地图是否提高场景选择效率”，无需同时承担内容运营和长期地点库建设。
- 定位拒绝后仍可搜索地点或上传风景照，延续 D-004 的可选定位边界。

代价：地图只能从首页任务入口进入，不利于无明确创作意图时闲逛和收藏地点。

## 未采用方案：一级“发现”地图

将底部导航的“灵感”改为“发现”，地图长期保留在一级页面；用户可以浏览附近景点、切换城市、收藏场景，再从选中卡片开始创作。风格灵感作为发现页的地图／内容视图之一。

收益：更接近参考图，地图成为产品记忆点，也为地点收藏、路线和本地内容运营留下空间。

代价：改变已有信息架构；需要处理地图与风格灵感的关系、非定位用户的默认内容、跨城市浏览、收藏、地点数据质量和更高地图服务成本。它不应作为“小改动”静默进入当前 MVP。

## 推荐页面内容

1. 顶部：返回、可点击的当前城市、搜索景点或区域、定位回到当前位置。
2. 筛选：推荐、自然风光、城市地标；后续可验证是否需要“适合日落”“人少”等动态条件。
3. 地图标记：照片缩略图、景点名称、画面类型；聚合过密标记，避免遮挡。
4. 选中卡片：景点、距离、当前推荐光线、可用机位数量、示例图和唯一主操作。
5. 恢复：定位拒绝或超时后，地图仍可搜索城市与地点，并提供上传风景照入口。

## 城市选择规则

- 点击顶部城市名称打开城市选择层，同时展示“定位当前城市”、城市搜索、最近使用与常用城市。
- 只有用户主动点击“定位当前城市”或地图定位按钮时，才先解释用途并请求系统定位权限；进入地图不自动弹权限。
- 手动选择城市不请求定位权限。此时展示城市级场景，但隐藏与用户当前位置有关的距离和方向，改为“城市浏览”。
- 定位成功后，展示当前城市、附近距离与回到当前位置能力；定位失败、超时或拒绝后，城市选择层保持可用并推荐手动选择。
- 首次使用且没有最近城市时先打开城市选择层；后续默认恢复用户上次使用的城市，不自动重新定位。
- 切换城市会清空当前选中的场景并重新加载地图；场景分类筛选可保留，避免重复设置。
- 最近城市只保存在设备本地；MVP 不要求账户同步。

## 候选规则

- “推荐”必须有可解释依据，例如距离、当前光线、场景素材可用性；没有依据时只称“附近”。
- 地图标记代表可用于创作的场景，不把普通 POI 全量铺到地图上。
- 距离和当前方向需要定位；拒绝定位时不伪造距离，改显示城市级结果。
- 景点预览需区分参考图、用户上传图和 AI 重构示例；素材来源规则仍受 D-003 约束。
- 选中场景不等于开始生成；仍需经过肖像授权、风格和生成确认。
- 当前原型中的地图、距离、机位和光线全部为模拟数据。

## 关键状态

| 状态 | 用户看到什么 | 恢复方式 |
| --- | --- | --- |
| 首次进入 | 有最近城市则恢复地图；没有则打开城市选择层 | 继续浏览或切换城市 |
| 城市未确定 | 城市选择层，定位与手动选择并列 | 定位当前城市、搜索或选择常用城市 |
| 定位中 | 地图骨架与定位进度 | 超时后重试或搜索 |
| 定位成功 | 当前城市、附近可创作场景与距离 | 筛选或移动地图 |
| 定位拒绝 | 城市级地图与搜索，无虚假距离 | 搜索地点、手动选城市、上传风景照 |
| 手动选城 | 所选城市的可创作场景，不显示个人距离 | 随时切换城市或主动开启定位 |
| 地图无结果 | 当前区域没有可用场景 | 扩大范围、清除筛选或上传风景照 |
| 标记聚合 | 数量标记而非重叠卡片 | 放大地图查看 |
| 场景选中 | 底部场景卡与主操作 | 切换标记或继续创作 |
| 地图加载失败 | 保留搜索与已缓存信息 | 重试或改用列表模式 |

## 可证伪验收候选

- M-01：定位成功后，用户能在地图上区分未选和已选场景，并看到对应底部卡片。
- M-02：用户选择场景后，能够继续到统一肖像步骤，且场景选择不会丢失。
- M-03：拒绝定位后，页面不阻断用户，仍能搜索地点或上传风景照。
- M-04：地图无结果或加载失败时，有列表、搜索或上传之一作为恢复路径。
- M-05：屏幕阅读器能够读出景点名称、选中状态和主操作；不只依赖地图坐标或颜色。
- M-06：用户无需授予定位权限即可手动选择任意支持城市并浏览场景；页面不显示虚假个人距离。
- M-07：用户主动选择定位、手动选城或切换城市后，顶部城市名称、地图内容和距离口径保持一致。

## 未知项

- 用户进入附近入口时，更想“马上选一个推荐”还是“在地图上自由探索”。
- 地图标记显示景点、具体机位，还是两层对象；两者的数据成本差异很大。
- “当前光线”“人少”等动态推荐是否有可靠数据，还是只能作为编辑内容。
- 地图服务、地点图片与路线数据的来源、费用和首发市场适配。
