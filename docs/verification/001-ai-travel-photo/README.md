### 当前限制与发布前条件

- OpenStreetMap 标准瓦片和公共 Nominatim 均是无 SLA 的尽力服务；当前仅适合开发和小规模产品验证。大量用户或商业发布前需要改用可承诺容量的供应商、自托管服务或受控代理。
- 地点搜索严格为用户提交触发，没有实现自动补全；客户端限制为每秒最多一次，并缓存当前会话内重复查询。`SCENIC_ME_GEOCODING_URL` 可在编译时替换服务地址。
- 最近城市通过系统键值存储保留最多六项，仅保存城市名，不保存精确坐标。组件测试已覆盖跨创作流程恢复；卸载应用后数据会随应用数据清除。
- Android 调试包已成功构建，但本轮没有 Android 实机或模拟器运行证据；系统权限弹窗、GPS 和反向地理编码仍需 Android 设备复验。
- 尚未验证拒绝后再次授权、定位服务关闭、弱网／离线瓦片、搜索限流、VoiceOver／TalkBack 完整顺序及长期缓存容量。
